# Grocer App Skeleton

This project is a groceries management app skeleton with the following features:

- Pantry inventory management
- Barcode scanner integration
- Favorites list
- Manual price entry
- Integration with one store API for grocery items

## Structure
- `frontend/` — React + TypeScript (Vite) app
- `backend/` — Node.js + Express API

## Getting Started

### Frontend
1. `cd frontend`
2. `npm install`
3. `npm run dev`

### Backend
1. `cd backend`
2. `npm install`
3. `npm run dev` (to be set up)
